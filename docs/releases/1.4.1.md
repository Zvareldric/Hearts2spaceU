# Release 1.4.1 — Release Gate Record

> **Tanggal:** 2026-10-25 · **Build:** 1.4.1 (2) · **Gate:** PRD §13

Pertama kalinya build **rilis** dijalankan di platform sungguhan. Test (535) tidak
bisa melihat konfigurasi platform — dua bug di bawah hanya muncul di sini.

## Hasil per platform

| Platform | Hasil | Bukti |
|---|---|---|
| **Android** | ✅ lolos | APK rilis terpasang & berjalan di emulator Pixel 8 (Android 16, arm64). `INTERNET` ada di manifest APK. Data kalender, update, dan cover termuat. Start dingin 2,8 s (4,2–4,7 s setelah data app dihapus — angka emulator, bukan ponsel). |
| **macOS** | ✅ lolos | `Hearts2spaceU.app` rilis berjalan; entitlement `network.client` ada di binari bertanda tangan; cache di container sandbox berisi 1.707 baris kalender yang diambil saat diluncurkan. |
| **iOS** | ⛔ belum terverifikasi | Mac ini belum punya komponen platform **iOS 26.5** (Xcode › Settings › Components). Build perangkat maupun simulator gagal karenanya. |

## Bug yang ditemukan gate ini (sudah diperbaiki, #21)

- Event `[CANCELLED]` tampil seolah tetap berlangsung, dan bisa menjadi "Up next".
- Pembaca baru tidak pernah melihat "Updated …" sampai app di-restart.
